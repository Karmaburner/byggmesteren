# Byggmesteren i Hringariki

Demo fra Lilit Labs for et oppdiktet byggmesterfirma i Hønefoss. Firmaet finnes ikke.

- `npm run dev -- --port 3130` starter siden lokalt.
- `npm run build` lager ferdige filer i `out/`.
- Alt innhold om firmaet står i `lib/firma.ts`.
- Tegningene er SVG i `components/Tegninger.tsx`.
